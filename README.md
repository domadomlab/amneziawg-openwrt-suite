# AmneziaWG 2.0 & Shuka Hybrid Suite (OpenWrt aarch64)

Комплексное решение для обхода блокировок на роутерах с архитектурой aarch64 (версия 4.0.0 LTS).

## 🚀 Два мощных движка в одном флаконе

### 1. AmneziaWG (Pure)
- **Engine**: `amneziawg-go` (User-space implementation).
- **Назначение**: Максимально легкий и быстрый VPN с параметрами маскировки (Jc, S1, S2, H1-H4).
- **Управление**: Меню **Services -> AmneziaWG**.
- **Фишка**: Автоматический Rollback (Health Check), если VPN не завелся.

### 2. Shuka (Sing-box Hybrid)
- **Engine**: `sing-box` (v1.13+).
- **Назначение**: Обход сложных блокировок через протоколы **VLESS**, **Reality**, **Shadowsocks**.
- **Интеграция**: Идеально работает с подписками из **3x-ui**.
- **Управление**: Меню **Services -> Shuka VPN**.
- **Фишка**: Интерактивный выбор серверов и переключение "на лету" прямо из LuCI.

## 🛠️ Установка

Загрузите релизный архив на ваш роутер (например, в `/tmp`), распакуйте и запустите нужный скрипт:

### Основной блок (AmneziaWG)
```bash
./install.sh
```

### Гибридный блок (VLESS/Reality)
```bash
./install_shuka.sh
```

## 📖 Как пользоваться Shuka
1. Скопируйте ссылку на подписку (или JSON-конфиг) из вашей панели **3x-ui**.
2. Перейдите в **Services -> Shuka VPN**.
3. Вставьте URL в поле подписки и нажмите **ОБНОВИТЬ СПИСОК**.
4. В появившемся списке выберите нужный сервер (клик по плитке).
5. Нажмите **СТАРТ**.

## ⚠️ Важное примечание
Не рекомендуется запускать оба движка одновременно. Это может вызвать конфликты в таблицах маршрутизации и привести к потере интернета. Используйте либо AmneziaWG для обычных нужд, либо Shuka для обхода GFW-подобных блокировок.
